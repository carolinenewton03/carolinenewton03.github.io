Featured Analytics Project
AI Job Market Dashboard

A data analytics project focused on understanding AI job trends, salary patterns, skill demand, and role distribution through dashboard storytelling.

Project Walkthrough
Problem

AI jobs are growing fast, but the market is messy.

Job seekers need a clearer view of which AI roles are hiring, which skills appear most often, and how salaries vary across role types. This dashboard turns scattered job-market data into an easier decision-making view.

Workflow

From raw listings to dashboard-ready insights.

The project follows a typical analyst workflow: clean the data, standardize role categories, extract skill signals, create measures, and build visuals that answer business-style questions.

  • Cleaned fields: job title, company, location, salary, experience level, and skills.
  • Created categories: Data Analyst, Data Scientist, ML Engineer, AI Engineer, and related roles.
  • Built visuals: salary distribution, top skills, location trends, and role demand.
